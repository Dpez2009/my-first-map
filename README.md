
# "Memorable places map"


## What did I build?

[This map](https://dpez2009.github.io/my-first-map/) is about places that I've been to in my life. Usually I like to focus on my first time being there, and what I done there.

## Users can...
1. **Toggle through all the points**, by tapping the black points on the screen
2. **See pictures of the place** 
after tapping on the points on the screen
1. **See what ive done there**
